# Risk-Aware IoT IDS Reproducibility Package

This repository supports the manuscript **"Risk-Aware Conformal Prediction for IoT Intrusion Detection: Coverage, Calibration, and Deployment Cost"**.

The package contains the code, experiment configurations, leakage reports, sampling manifests, aggregate metrics, diagnostics, generated LaTeX tables, and anonymous manuscript source needed to audit the reported workflow.

## Repository Layout

- `src/iot_ids/`: data preparation, preprocessing, model training, calibration, conformal prediction, metrics, and reporting utilities.
- `experiments/`: JSON configurations for dataset preparation and the reported experiment matrices.
- `results/`: included aggregate metrics, diagnostics, environment manifests, and sampling manifests.
- `paper/`: anonymous LaTeX manuscript source, bibliography, and generated table inputs.
- `tests/`: unit tests for data handling, calibration, conformal prediction, metrics, reporting, and run-script checks.
- `scripts/`: reproducibility utilities for downloading CIC data, verifying raw files, auditing results, recording environments, and generating manuscript tables.

## Data

Raw datasets are not redistributed. Download them from the original providers and place them under `data/raw/`:

- CIC IoT-DIAD 2024: https://www.unb.ca/cic/datasets/iot-diad-2024.html
- UNSW-NB15: https://research.unsw.edu.au/projects/unsw-nb15-dataset

The included `DATA_NOTICE.md` describes what is included and what must be regenerated from the public datasets.

## Environment

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

The experiment configurations set `xgboost_device` to `cuda`. Change it to `cpu` if CUDA is unavailable.

## Reproduce The Reported Tables

The repository includes the aggregate CSV files used for the manuscript tables. To regenerate the LaTeX table inputs from those CSV files:

```powershell
.\.venv\Scripts\python.exe -B -X utf8 scripts\make_manuscript_tables.py
```

## Run Tests

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

## Re-run Experiments

After placing the raw datasets under `data/raw/`, the full experiment script verifies raw files, prepares train/calibration/test splits, records the environment, runs the current model matrices, evaluates results, regenerates tables, and audits key output directories:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\run_full_experiments.ps1
```

The main reported configurations are:

- `experiments/manuscript_prepare_config.json`
- `experiments/cybersecurity_cic_raw_proportion_prepare_config.json`
- `experiments/cybersecurity_core_latency_calibration_config.json`
- `experiments/cybersecurity_raw_prop_latency_refresh_config.json`

## Reproducibility Rules

- Preserve official train/test splits when a dataset provides them.
- Fit preprocessing only on the training split.
- Fit probability calibration and conformal thresholds only on held-out calibration rows.
- Do not use flow IDs, IP addresses, `attack_cat`, timestamps, source-file provenance, or post-event identifiers as model features.
- Read manuscript numbers from generated CSV and table files rather than transcribing values by hand.
- Do not interpret workstation latency as optimized edge-device serving latency.
- Large `raw_predictions.csv` files are regenerated by the experiment script and are not included in this public package.
