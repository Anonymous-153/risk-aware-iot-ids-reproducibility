# Data Notice

This repository does not redistribute the raw public datasets used in the manuscript.

The CIC IoT-DIAD 2024 dataset should be obtained from the Canadian Institute for Cybersecurity dataset page:

https://www.unb.ca/cic/datasets/iot-diad-2024.html

The UNSW-NB15 dataset should be obtained from the official UNSW dataset page:

https://research.unsw.edu.au/projects/unsw-nb15-dataset

The repository includes code, experiment configurations, leakage reports, sampling manifests, generated tables, aggregate summaries, per-run metrics, diagnostics, and environment manifests needed to audit and reproduce the reported workflow. Full processed split files, raw public datasets, fitted model files, and large raw prediction files are intentionally excluded and can be regenerated by following the commands in `README.md` and `SUPPLEMENTARY_README.md`.
